# FinGuard: Financial Transaction Anomaly Detection and Risk Assessment System

## Project Overview
FinGuard is a web-based application designed to analyze financial transaction data, identify potentially suspicious activities, and assess transaction risk levels.

## Features
- Transaction data analysis
- Suspicious transaction detection
- Risk score calculation
- LOW, MEDIUM, and HIGH risk classification
- Interactive dashboard with charts
- Transaction details and risk explanations
- User authentication and admin management

## Technologies Used
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
- Pandas
- NumPy
- Chart.js

## Installation and Setup

1. Install Python 3.x.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open the local URL displayed in the terminal in your web browser.

## Project Note
FinGuard uses rule-based analysis to identify unusual transaction patterns in prepared transaction data. It is an academic project and does not connect to live banking systems.
